\section*{Data Availability}
The anonymized repository is at
\url{https://anonymous.4open.science/r/SemWeaver-FD1E/}.
Its English replication package contains the implementation, 39 frozen
generated-only checker and patch inputs, Clang raw-output/provenance bindings,
the actual KNighter and \toolname outputs, model exchanges, repeated-subset
results, and an offline verifier. Historical manual and mixed-provenance
materials are excluded from the scored results.
Full reruns require public Linux revisions and the pinned toolchain; the
curated package is intended to remain public upon acceptance.
