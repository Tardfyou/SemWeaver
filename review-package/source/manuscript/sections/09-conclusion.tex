We presented \toolname, an automated post-synthesis checker editor with provenance-labelled analyzer context and a paired-warning gate. On 39 frozen generated-only CSA checkers, its GPT configuration reaches seven patch-discriminating successes versus one for KNighter's actual loop; on the directly matched 15 fixed-noisy cases it retains 60 fixed-side object alerts versus KNighter's 72 while keeping all vulnerable revisions warning-positive. The full-cohort no-internal ablation ties the native condition, so an incremental causal benefit from internal records is not established here. The evidence supports bounded patch-local warning-noise reduction and warning recovery, not independently adjudicated target recall or unseen-site vulnerability generalization.
