# SemWeaver: English review-material guide

**Staging status: not the final published artifact.** The full39 main comparison
is closed; auxiliary experiment completion, manuscript agreement, final exported
verification and anonymous publication remain pending. This guide must not be
used to certify the older published package as containing the new results.

## Start with the actual denominators

- `FINAL39_SUMMARY.json` and `main39-tables/`: all39 subjects, starting checkers,
  native/no-internal refinement and actual KNighter workflow. `CASE_TABLE.csv`
  includes all156 starting/method-subject rows, not a favorable subset.
- `MAIN39_FINDINGS.md`: full-cohort tradeoffs and the preexisting15-subject
  report-refinement stratum. Native's full-cohort F1 does not exceed no-internal;
  the stratum's lower report burden is concentrated in G24.
- Repeated ablation: the original12 subjects, three decodes per arm, first
  reused from the main experiment;48 additional executions. Repeated decodes
  are not new independent bugs. The final auxiliary summary is created only
  when every planned execution passes its integrity gate.
- Model sensitivity: the same12 across three native configurations, one decode
  each,36 cells with a2-response/65536-output ceiling. This is not all39
  cross-model robustness or a cross-model native-versus-control experiment.

## Evidence and examples

`EVIDENCE_ORIGINS.md` and `INITIAL_EVIDENCE_CATALOG.json` define actual origins,
interfaces, schemas and193 initial records. `NATIVE_EVIDENCE_AVAILABILITY_STATUS.json`
separately records usable/unavailable dynamics for150 native-chain attempts.
Missing, unsupported or capped observations do not establish safety.

`MOTIVATING_EXAMPLE_DECISION.md` distinguishes the main G21 checker from the
separately fixture-guided model-produced illustration. Both retain an original
Linux1/0 pair, but their fixture outcomes and response budgets differ. The
illustration's114 successes are not transferred to the one-response main checker.
All current failures and older automatic refinement lineage remain available.

Version-level warning metrics are not independently adjudicated target recall
or deployment precision. Fixed-side reports are a burden measure, not a count
of independently confirmed false-positive bugs. The controlled-fixture
retention guard is native-only; its costs and actual rejection counts are disclosed.

## Final export requirements

The release must include generated inputs, scored and rejected candidates,
actual available prompts/replies, normal paired scans, unavailable/error/repair
receipts, and raw native evidence. Superseded configurations remain separately
labeled and cannot supply missing canonical cells. Local evidence aliases must
be flattened without following external worktrees or copying rebuildable caches.

All explanatory documentation is English. Raw model/tool output remains as
emitted; translations are identified as translations. Machine identifiers and
private endpoints are redacted with original/public hash crosswalks. Private
credentials, original Overleaf/history backups, Linux worktrees, virtual
environments, CodeQL databases and rebuildable binaries are excluded.

No new project-level license is granted. Included adapted KNighter code retains
its upstream license/notices, and included Linux material retains its notices.
The package is provided for review. Final offline verification, manuscript
compile/render checks and actual anonymous-mirror verification precede release.
