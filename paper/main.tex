\section*{Data Availability}
The anonymized repository is at
\url{https://anonymous.4open.science/r/SemWeaver-FD1E/}.
The English package contains implementation, frozen inputs, raw-output/provenance
bindings, both systems' outputs, original exchanges with English reading companions,
all reported repeated/model-subset results, and offline byte/reaggregation checks.
Historical manual/mixed-provenance materials are unscored. Full reruns require
public Linux revisions and the pinned toolchain; the package is intended to remain
public upon acceptance.
